## P1 · 誰來用

### 核心主張

> **任何想學點什麼的人。**
> 不是「大學生」，不是「轉行的人」，不是「考生」。
> 是一個年齡層、學科、職業都推廣得起的東西。

### 為什麼必須這樣講（這不是為了討好聽眾）

我們的機制有三個特性，使得它**不受限於任何一個場景**：

| 機制 | 為什麼能跨場景 |
|---|---|
| **用戶帶資料，課從資料長出來** | 換科目 = 換檔案。系統不需要重新學「數學怎麼教」 |
| **記憶是畫像，不是知識庫** | 存的是「他偏好什麼講法、他在哪裡卡住」，不是「數學第一章有什麼」 |
| **自由度高** | 重抽整門課、改教法、換間隔——全部用戶自己決定 |

**→ 這三點是我們的技術護城河，也是「服務所有人」的根據。**

⚠️ **措辭紀律**：這一句**不能單獨講**。必須緊接著講「那我們從哪裡開始」——否則會被問「那你們到底做給誰」。

### 版面

```
任何人想學點什麼，就能用

        ┌──────────┬──────────┬──────────┬──────────┐
        │  小學生  │  中學生  │ 大學生   │  在職進修 │
        │ 語文/數學 │  DSE/公開 │  課堂複習 │  換工作   │
        │          │  考試    │  論文題目 │  技術要求 │
        └──────────┴──────────┴──────────┴──────────┘
              同一個機制，換的只是上傳的檔案

        邊界：學習之內的事我們不插手
              學習之外的事（找課、備題、排程）全部包辦
```

### ⛔ 本頁禁用

| 禁用 | 原因 |
|---|---|
| 「不限於單一垂直場景」當成市場定位講 | 這是**產品設計理念**。單獨講等於「還沒想清楚服務誰」 |
| 任何「TAM 幾千億」數字 | 查不到可核實方法論 |
| 「全科全年齡」之後不接「我們從哪開始」 | 會被問「那你到底做給誰」 |

### 講者備註

這頁是全場最容易被問倒的一頁。**不要只講「所有人都能用」就停**——要立刻給一個具體的入口情境，讓聽眾自己套進去。

最好的講法是舉一個聽眾沒預想到的例子：藥劑師要溫習統計學、教師要備一門課、家長要陪小孩做中文。**這三個例子都在同一個機制裡。**

### 核心主張

> **四家都在「賣你東西」。只有我們在「每天陪你學」。**
> 而其中兩家，在香港中文使用者最需要的地方，是關著的。

| 事實 | 為什麼要自己講 |

### ⛔ 本頁禁用

| 禁用 | 原因 |
|---|---|
| **「他們都沒有語音」** | **已被 Coursera 自己的官方文件推翻**（Role Play，2026-07-08）。上片會被直接反駁 |

| Coursera 付費訂戶 / ARPU | 2026-05 與 Udemy 合併後**已停止披露**；ARPU 從未披露 |

### 講者備註

這頁的講法是**先承認對手強，再講結構性差異**。

不要說「它們沒有語音」——Coursera 有。誠實講：Coursera 有語音對話，但**它不支援中文，也不支援手機 App**。這兩條對香港學生是致命的，而且是他們自己文件寫的。

Hyperknow 那邊，重點不是價格，是**它沒有手機 App，而且自己叫用戶不要上載機密資料**。

## P3 · 怎麼收錢

### 核心主張

> **按你實際講了多少秒語音收錢。不是按次，不是按課時，不是按你多久沒登入。**

### 三檔

| | **免費** | **Pro** | **Max** |
|---|---|---|---|
| **月費** | HK$0 | **HK$148** | **HK$388** |
| **每天 短講解（5 分鐘）** | **2 節** | **12 節** | **25 節** |
| **每天 完整課（12 分鐘）** | — | **5 節** | **10 節** |
| **每月 語音時長** | 5 小時 | **30 小時** | **60 小時** |
| 每積分成本 | — | **HK$0.0036** | HK$0.0036 |
| **毛利率** | — | **71%** | **78%** |

### 三條計費原則

1. **只在創造新東西時扣**，看已生成的內容免費
2. **生成失敗、或你取消，全額退回**
3. **每天發放，累積七天**——不用會累積，不會作廢

### 與對手的結構差異（一句話）

> **別人的積分，買的是「你問了幾次」。我們的積分，買的是「講了多少秒聲音」。**
> 差別是：你可以問到飽，因為問問話不另外收錢。

### 為什麼這樣收（三個理由，每個都要講）

| 理由 | 說明 |
|---|---|
| **成本事前可算** | 文案字數在開課前就定，扣多少用戶看得到。**對手做不到這一點**——用戶問一句才燒一次推理 |
| **成本極低，所以敢給多** | 每分鐘語音 HK$0.022。**能給 30 小時是因為成本真的低** |
| **追問免費不是讓利** | 追問的邊際成本只佔單節課 0.9%。**收費只是計量手段，不是成本回收** |

### ⛔ 本頁禁用

| 禁用 | 原因 |
|---|---|
| **任何積分數字**（1,800／11,250／22,500） | 積分按語音合成字數計價，對用戶沒有直觀意義。**講節數** |
| 任何量折扣的比較 | 我們 −32%，它 26%。兩套積分買不同的東西，這個比法會被算成「我們的 Max 反而更貴」 |
| 「Max 賣能力不賣量」 | Max 是 Pro 的 2.6 倍價只給 2 倍積分，這句會被追問 |
| 任何毛利數字（71%／78%） | 無帳單實測。**且網龍 Mynd.ai 教育業務實測只有 25.0%** |
| 逐月財務預測 | 分母是無錨點的用戶增長假設 |
| 「加油包是原價幾折」 | 全業界無公開數字可引 |

### 講者備註

P12 是前面所有頁的**兌現頁**。前面講「服務所有人」「對手關著的門」，這頁回答「那你怎麼賺錢」。

**不要講積分。** 講「每天幾節課」——這是我們賣的東西本身，不需要換算。

「追問免費」這條要特別停頓一下，因為它是我們與對手最直接的反差，而且**Hyperknow 每提問一次扣 1 分**。這一句是全場最容易被記住的。

## P4 · 人從哪來

### 核心主張

> **不是靠投廣告。靠的是：學生之間傳開，以及學校。**

### 為什麼不能靠付費流量（這一頁的誠實前提）

| 項目 | 數字 |
|---|---|
| 香港補習類 CPC（多個來源區間） | HK$6–20 [C，**無權威公開基準**] |
| Freemium → 付費中位數 | **2.18%** [B] Adapty，16,000+ apps |
| 推算 CPA | **HK$275–917** |
| Pro 6 個月毛利 | **HK$630** |
| **判定** | **CPA 在毛利之上 44%–145%，不可持續** |

> ⚠️ **香港補習類 CPC 沒有權威公開來源。** 五個獨立來源互相矛盾（HK$1.8 至 HK$20）。Google 不發布細分市場 CPC。
> **要引用必須標明是估算。** 或自行開 Keyword Planner 實測。

### 真正可行的三條路

| 渠道 | 為何可行 | 成本 |
|---|---|---|
| **口碑轉介紹** | **香港教育市場的真實 CAC 路徑** | HK$100–300 [C] Kelly's Education 實測，2021，單一公司自述 |
| **學校（公帑資助）** | 渠道已開通 | 見下 |
| **短影音內容** | YouTube 香港每用戶每月 **22 小時 31 分鐘**，全港第一 [B] DataReportal | 製作成本 |

### 政府渠道（已開通，但我們零用戶）

| 項目 | 數字 | 來源 |
|---|---|---|
| **「智啟學教」撥款** | 三年共 **HK$5 億** | [A] 政府新聞公報 2025-12-16 |
| **每所成功申請學校** | **一筆過 HK$500,000** | 同上 |
| 用途 | **明文包含「購買／訂閱／租用」AI 輔助教學服務** | 同上 |
| **「智」為學理**（初中科學） | **220+ 所中學已獲 HK$100,000** | [A] 教育局 2025-12-23 |

> ⚠️ **這筆錢是給學校的（B2B），不是給學生家長的（B2C）。** 兩條線要分開講。
> ⚠️ **Sayo Academy 已在同一批撥款裡**（官網明示支援，自稱 200+ 所學校）。**我們不是先進入者。**
> ⚠️ 我們零用戶、零學校關係、產品原型未完成。學校採購週期 6–12 個月。

### 市場基本盤 [A 官方統計]

| 指標 | 數值 |
|---|---|
| **中學生人數（2025-09）** | **347,820**，較 2022 谷底 **+8.30%**（連升三年） |
| 小學生人數（2025） | 317,233（**連續下跌**） |
| 日間中學 | 513 所、12,531 班 |
| **DSE 2025 考生** | **55,781**（學校 45,478 + 自修 10,303） |

> ⚠️ **中學生在回升，但小學生在跌。** 中學窗口是 3–5 年，不是無限。**這是必須自己講的邊界。**

### ⛔ 本頁禁用

| 禁用 | 原因 |
|---|---|
| **香港補習市場規模任何數字** | 公開數字橫跨 HK$4 億至 HK$281 億（**相差 70 倍**），官方統計處不單獨公布補習開支 |
| **香港補習類 CPC 任何數字** | 無權威基準，五個來源互相矛盾 |
| 逐月的獲客預算 | 只有 [C] 估算 |
| 續訂率／LTV／CAC payback | 同類公司**全部未披露 churn** |
| 說「我們要進學校」但不提 Sayo 已在那裡 | 會被查 |
| 說「中學生人數在增長」但不提小學生在跌 | 這是選擇性引用 |

### 講者備註

P4 是最容易講成「我們會做很多推廣」的一頁。**要講的是「我們不做什麼」**。

先講付費流量算不過（這需要勇氣），再講所以我們只做三件事：口碑、學校、內容。

**學校那條要非常小心**。先講渠道存在（HK$5 億已開通），立刻講 Sayo 已經在那裡、我們零用戶。**主動講弱點比被問出來好。**

中學生人數 +8.30% 這條是好消息，但要自己補上「小學生在跌」。

### 三個評審重點（以 HKU 科創中心 Tech-Up 為例 [A]）

| 評審項目 | 權重 |
|---|---|
