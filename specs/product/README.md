## 核心概念速查

| 概念 | 定義 | 出處 |
|---|---|---|
| **循環單位** | **一節課（10–15 分鐘實時語音教學）**。這是整個產品最有價值的設計參數——一節課有完成態 | `veridex-product-philosophy.md` §4.1 |
| **設計哲學** | **自由度本身就是定制化。** 從頭到尾每一環用戶都可以推翻重來 | 同上 §3 |
| **跨時間連續性** | ChatGPT 每次從零開始；Veridex 記得你上次卡在哪 | 同上 §5① |
| **追溯而非重做** | 錯題不重做，追溯到真正不會的那一層，只補那一塊 | 同上 §5② |
| **降低認知負荷** | 學習之外的事全部包辦。**邊界：學習之內的事我們不插手** | 同上 §5③ |
| **Web／App 呈現** | **功能與版面／資訊架構一致；僅視窗適配。** 同一主導航與主畫面（生成／課堂／共享／問答）；側欄⇄底部 Tab 等 chrome 適配；帳戶／積分／進度共用 | `web-app-presentation.md` |

## ⚠️ 兩份文件間的邊界

有些設計**同時是產品決策和經濟決策**。分工如下：

| 主題 | 產品面講什麼 | 經濟面講什麼 |
|---|---|---|
| **追溯閘門** | 自由度：追到哪裡、用什麼方式講 | 成本控制：遞增定價、配額、深度探索模式 |
| **觸頂不阻斷** | 體驗：降級是狀態不是懲罰 | 定價：降級策略與毛利的關係 |
| **加油包** | 不講 | 面額率、級距、與 Max 價格的聯動 |
| **升級觸發點** | 「記憶斷層」這句話怎麼說 | 升級牆的設計與轉化率假設 |

**同一件事的兩面各歸各位，正文互相引用。**


## 计划书语气与第四核命名锁（2026-10-17）

详见 hk-business-glossary.md §0b。摘要：

- 全文「我们」；对外避免「口径」；语气向 Shopify 早期白话靠拢。
- 第四核**能力**＝随时＋课中；**对外标题**＝「就这一节的随堂提问／随时问正在学的内容」（勿以「AI 基本问答」作 headline）。
- 产品开发＝**两人自研、不外包**；招聘首年约十余人量级（勿写 100 人）。
- 学校渠道仅脚注／表下补充，不入本轮收入模型。

对齐笔记：../../book/specs-align-after-notion.md（及 box /workspace/clc-rewrite/out/specs-align-after-notion.md）。
