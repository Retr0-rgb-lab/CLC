## 2. 单位经济（Stripe 后）— 已复核，与 docs 一致

**费率公式**（Stripe 香港本地卡）：`3.4% + HK$2.35 / 笔`（`veridex-pricing.md` §10.2 [A]）。

### 2.1 验算（2026-10-16 本文件重算）

| 项目 | Pro（HK$148） | Max（HK$268） | 验算结果 |
|---|---|---|---|
| Stripe 费 | 148×3.4% + 2.35 = **7.382** → 文档 **HK$7.38（5.0%）** | 268×3.4% + 2.35 = **11.462** → 文档 **HK$11.46（4.3%）** | ✅ 一致 |
| 净收入 | 148 − 7.38 = **HK$140.62** | 268 − 11.46 = **HK$256.54** | ✅ 一致 |
| 月模型成本（文档锁定） | **HK$40.37** | **HK$80.73** | 见下「不一致说明」 |
| 贡献毛利 | 140.62 − 40.37 = **HK$100.25** | 256.54 − 80.73 = **HK$175.81** | ✅ |
| 毛利率（净收分母） | 100.25 ÷ 140.62 = **71.3%** → 文档 **71%** | 175.81 ÷ 256.54 = **68.5%** → 文档 **69%** | ✅ |

`0.75×100.25 + 0.25×175.81 = **HK$119.14 / 月**` ✅ 与 `veridex-financial-model.md` §1.1 一致。
