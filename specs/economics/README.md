**積分基準：1 積分 = 40 字語音。每積分成本 HK$0.0036**（Qwen3-TTS-VC $0.115/萬字，已核實官方頁）。

## 三個關鍵結論

1. **架構決定成本。** 從實時語音改為 LLM + TTS，單節課成本從 HK$1.55 降到 HK$0.271（**5.2 倍**）。
2. **分發決定毛利。** Stripe 5.0% vs App Store 15%——**先做網頁付費**。
3. **錢不是瓶頸。** 18 個月累計盈利 HK$1,479,549，只需啟動資金 HK$4,626。**瓶頸是用戶增長能否達成。**
