## 1. 禁用清單（任何一條都不許出現在投影片上）

### 1.1 查證後確認為假

| 禁用 | 原因 |
|---|---|
| 「一周後落後 21 個百分點」 | Roediger & Karpicke (2006) 摘要裡沒有任何百分數，數字查不到來源 |
| 「Dunlosky & Rawson (2012), Science」 | 期刊是 *Learning and Instruction* 22(4):271–280；出版社刪除摘要，效應量不可用 |
| Dunlosky & Rawson 的**任何數字** | 同上 |
| 「Karpicke & Blunt 2011 的 80／36／61%」 | 論文存在但具體百分數拿不到 |
| 「即時測 90%、一周掉到 40%」 | 查不到可核實來源 |
| 「錯誤有多少比例來自前置知識缺陷」 | 完全查不到，沒有研究給過這個百分比 |
| 「84 萬註冊／5% 拿證書／35% 從未看過」 | 查不到 |
| 「學習是相對持久的行為改變」 | 追溯來源查不到一手出處 |
| OpenMAIC **AGPL-3.0** | 是 MIT |
| ChatGPT **Plus US$20** 那一行 | 無出處 |

### 1.2 流行說法，不是文獻

| 禁用 | 原因 |
|---|---|
| 「注意力只能維持十分鐘」 | Wilson & Korn (2007) 標題是 *Beyond Ten Minutes*，該文在反駁此說法 |
| 署名 **WIDS** | 查無此縮寫及原文出處 |
| 「輸入—處理—輸出—反饋」當**學術定義** | 查無權威出處 |
| 加涅「**八階段**」順序 | 順序與名稱未能核實 |
| 「反饋階段是循環的閉合點」 | 查不到任何權威表述 |
| Black & Wiliam「0.4–0.7 SD」 | 來源是 1998 年那份報告，不是期刊論文 |
| 「檢驗這格沒人做」「他們沒做反饋」 | **事實錯誤**（StudyFetch / Mindgrasp / Quizlet 都有）。只能說「公開資料裡看不到任何一家說明……」 |

### 1.3 自造詞（已明確否決）

「**第 N 格**」「第四格是空的」「**回到起點**」「**最小閉環**」「乘客回到起點」——全部禁用。

**禁令針對的是「純序號指代」**：光寫「第 4 格」而不說那是什麼，聽眾就不知道你在講什麼。凡是用序號的地方，**同一頁內必須同時出現那個項目的名字**（如 P5 的「① 喚起先備」而不是單獨的「①」）。完全不帶名字的序號，以及「前一頁說的那個」這類回指，一律禁用。

### 1.4 已作廢的設計

| 作廢 | 原因 |
|---|---|
| 「**評分權交給授課教師**」 | 本項目**全程 AI native，不聘教師、不設仲裁** |
| 「誰來判」這個維度 | 同上，不存在 |

### 1.5 不要把不利資訊做成一頁投影片

**我們的弱點不寫在投影片上。** 例如「機器給開放題打分與人一致率只有 52%」這類研究結果，**不得成為任何一頁的主題**。它留在研究筆記裡，供答問時準備，不進正片。

## 2. 逐頁規格

---

### P1 · 封面

```
Veridex：AI 時代的有效自學方案
按你的資料生成，按你的程度驗收
```
底部：`呈：青年創業基金委員會` ｜ `講者：黃浩然、黃羿捷` ｜ `2026 · 10 · 16`

- ❌ 不得用宗旨式標題（「把學會變成可檢驗的事」已否決）
- ❌ 副標不得用與 hero 語義重疊的形容詞（「高質量學習方案」已否決）

---

### P2 · 傳統課堂給不了定制

**頂部歸因**
> 老師的注意力是稀缺資源 —— 一份講義、一條進度，都只能按一個人來做

**兩列三對，一一對應**

| | 左：傳統課堂 | 右：AI native 課堂 |
|---|---|---|
| 1 | 講義是發給所有人的，不是給你的 | 課照著你的資料長出來 |
| 2 | 一條進度，快的被拖、慢的掉隊 | 進度跟著你的水平：快的跳過，慢的加時 |
| 3 | 老師不知道你想學什麼 | 你說什麼，第一課就是什麼 |

**動畫**：先出左列三條 → 再出右列三條

**硬性守線**：本頁**只講定制，不講檢驗**。右列禁止出現「打斷、追問、實時糾正、反饋」——那些屬於 P8 及以後。

**表述紀律**：不得說「老師做不到定制」。要說的是**注意力的邊際成本**，不是規模——否則「國際學校 8 人小班」一句就破。

---

### P3 · 我們怎麼造這門課

**左欄三步**（② 高亮，配小字「傳統課堂永遠不會做這一步」）
```
① 上傳資料，說清需求
② 了解現狀，摸清程度        ◀ 高亮
③ 生成課程，帶有檢驗
```

**右欄**：產品原型圖（**課程頁**）—— `ImagePlaceholder`，提示「Veridex 課程頁截圖：章節、知識點、語音講解、板書同步」。原型圖由使用者之後補上。

**落點**：課出來了，**那個檢驗算不算數？**（同一頁不得重複出現「傳統課堂永遠不會做第②步」——② 下方的小字已經承載了這句）

**動畫**：① ② 依次 → ③ → 右側原型

**寫作紀律**：第 ② 步是「了解現狀，摸清程度」這樣的中性描述，**不是「AI 精準診斷」這種自誇**。這一頁的功能是讓「按你的」三個字有兌現的動作。

---

### P4 · 上課時

**講定制化的第二個時刻**：出課時定內容與起點（P3），上課中調節奏（本頁）。

```
AI 講解，白板板書同步推上去
你隨時可以打斷、追問、要求換一種講法
進度按你的反應走——跟不上就停下來重講
```

**動畫**：三條逐條出。

**硬性守線**：本頁屬於**定制**不是**檢驗**。「打斷、追問」是節奏調節（我跟不上你就不往下走），**不是反饋**（我答錯了你告訴我錯在哪）。措辭上不得出現「答錯」「判斷」「反饋」。

**視覺**：與 P2 右欄呼應——同樣的藍色、同樣的句式，讓評委看見「這就是 P2 說的定制」。

---

### P5 · 學習的本質：要走完四步

**依據**
> Merrill, M. D. (2002). First principles of instruction. *Educational Technology Research and Development* 50(3):43–59. doi:10.1007/bf02505024

**表述紀律（硬性）**：Merrill 這是**課堂教學設計原則**，不是「學習者的認知過程」。**標題用大白話講它解決什麼，出處放腳註**——先說人話，再給文獻。

```
學會一件事要走完四步

① 喚起先備      你：把已經會的調出來
② 示範          AI：講給你聽
   ── 前兩步是聽，是輸入 ──
③ 應用          你：要自己做一遍
④ 整合          你：換個情境再用一次
   ── 後兩步必須動手 ──

動手之前，沒有人知道你到底會了多少。
→ 沒有檢驗，這四步走不完
```

**這四步的價值**：把「沒有檢驗」從**我們的偏好**變成**流程本身的必然**——③④ 必須動手，動手才知道會不會。所以檢驗不是加分項，是這條路走完的必要條件。

**禁止**：畫循環圖。「後兩步必須動手」用分隔線表達，不畫成回環。

---

### P6 · 靠學生自己，兩條路都堵死

**這兩條必須在同一頁**——它們是否證關係（A 逼出 B，B 回頭否掉 A）。分頁會讓 B 變成「順便說一下」。

```
出路一 ── 自己做檢驗
   多數人不做
   解釋概念 58% · 總結材料 47% · 研究思路 40% · 組織思路 39% · 搜索 25% · 生成 25% · 直接放進作業 11%
   ───────────────────────────────────
   檢驗我到底學會沒有        調查未列此項      ← 虛線、零長、琥珀
        ↓
出路二 ── 那就檢驗一下
   自己判：估準 18.5%　高估 35.5%　低估 46.0%
   這叫「元認知錯覺」——你對自己掌握程度的判斷，和真實水平不一致
        ↓
   不做，看不到結果；做了，拿到的是自己的錯覺。
```

**視覺**：橫向條形圖，最後一根虛線琥珀條代表「調查未列此項」。

**出處（頁腳）**
- HEPI (2026). *Student Generative AI Survey*, Report 199, n = 1,054，英國全日制本科生
- Knof, Berndt, Shiozawa et al. (2024). *BMC Medical Education* 24:1210. doi:10.1186/s12909-024-06121-7（文章編號 1210；Crossref 登錄號，非 923）

**術語紀律**：「元認知錯覺」**直接用，並緊跟一句白話解釋**。但**附錄不要列它的 DOI**（出處查不到）。

**措辭紀律**：虛線條寫的是「調查未列此項」，**不是「0% 的人用它」**。後者是推斷，會被反駁。

### P7 · 一題做錯了，四個問題

```
一題做錯了

  它掛在哪個知識點上？
  為什麼錯？
  要補哪一塊？
  多久之後再問我一次？

現在的產品大多只回答第一個。
我們回答四個。
```

**為什麼是純文字頁**：這是全場唯一一個幾乎沒有圖形、純靠字的重頁，而它緊接在 P6 那張密集數據圖之後——**它是需要的呼吸**。

**動畫**：四個問句逐條出 → 停頓 → 最後兩行結論。

**已否決的方案**：四行對比表（用戶明確否決，因為表格已經用過）。四個問句的「對比」由聽眾自己在腦中完成。

---

### P8 · 我們的檢驗，細在哪四個地方

**四行，全部 AI native。不得出現「誰來判」這個維度。**

| | 做法 | 對比的粗話 |
|---|---|---|
| **測什麼** | 講出來 / 練一遍 / 做出來 | 不止選擇題 |
| **追溯** | 追溯錯誤本因，追到你真正不會的知識點 | 不只追到這道題 |
| **給什麼** | 給正確思路，不給答案 | 不給你抄 |
| **測多久** | 間隔由 AI 推薦，你確認 | 不是拍腦袋定一個日期 |

**「測多久」那行的依據**
> Cepeda, Vul, Rohrer, Wixted & Pashler (2008). *Psychological Science* 19(11):1095–1102. doi:10.1111/j.1467-9280.2008.02209.x
> 原文摘要：最優間隔從「一周後測的 20–40%」遞減到「一年後測的 5–10%」

**可上台的推論**：間隔太短也不是最優——**間隔要跟著「你要測多久」來定，不能拍腦袋**。這讓我們站在文獻那邊，而不是那句科普裡常見的「越久越好」（後者是錯的）。

**寫作紀律**
- 「給什麼」是**純 AI 產品的專屬優勢位**——它同時回答了「AI 加速還是有害」這個問題
- **禁止**寫「評分權交給教師」——本項目不聘教師
- 本頁不舉例，三種形式的細節留到下一版

## 3. 設計系統（沿用現有常量）

| Token | 值 | 用途 |
|---|---|---|
| `ACCENT` | `var(--osd-accent)` = `#2F6BFF` | **填充、條形、邊框**（圖形，3:1 達標） |
| `ACCENT_TXT` | `#1B4FD8` | **文字用** |
| `AMBER` | `#C07A16` | 填充、邊框 |
| `AMBER_TXT` | `#8F5606` | **文字用** |
| `DIM` | `#5F6B79` | 腳註、頁碼 |
| `MUTED` | `#5A6675` | 次要文字 |

實測值（WCAG sRGB 公式，對 `#F6F7F9` 與白色合成底皆達標）：8 頁自撰文字**最低 5.07:1**。**勿引用舊規格裡的 4.6／5.6／5.9，那幾個數字偏低。**

**紀律**
- **全部淺底**，不使用深色頁
- **琥珀色只代表問題**（未通過、盲點、斷點、真正的不足）。Veridex 自己的正面內容一律藍色
- 文字用 `*_TXT`，填充用亮色，**不可混用**
- 正文下限 **22px**；次要文字不得低於 `#5F6B79`

**版式**：8 頁至少 6 種不同版式。已規劃：封面 / 左右兩列對照 / 流程圖+原型 / 逐條出 / 四步橫排 / 條形圖 / 純文字問句 / 四行表

**動效**：只有三種動作——幕間轉場 260ms、`Step` 逐條揭示、圖形連線描繪。禁止彈跳／旋轉／視差。

## 4. 技術硬約束

- 只用 `react` + `@open-slide/core` + 標準 Web API，不加依賴
- 不改 `package.json` / `open-slide.config.ts` / `tsconfig.json` / `slides/` 下其他 deck
- **不用 `array.map()` / forEach / reduce 渲染重複元素**——用顯式元件實例
- **不用 `overflow: auto|scroll|hidden`** 遮蓋溢出
- 畫布固定 1920×1080，裝不下就減內容，**不許裁切**
- 講者提示**絕不能出現在可見文字裡**，只進 `notes`
- `notes` 與頁面數組嚴格對齊
- `meta.createdAt` 保持 ISO 8601 字串字面量
- **繁體中文**（現在檔案裡有簡體，要改）
- **中文與英文之間不加空格**（寫 `Veridex：` 而非 `Veridex ：`）
