## ⚠️ 兩份文件間的邊界

有些設計**同時是產品決策和經濟決策**。分工如下：

| 主題 | 產品面講什麼 | 經濟面講什麼 |
|---|---|---|
| **追溯閘門** | 自由度：追到哪裡、用什麼方式講 | 成本控制：遞增定價、配額、深度探索模式 |
| **觸頂不阻斷** | 體驗：降級是狀態不是懲罰 | 定價：降級策略與毛利的關係 |
| **加油包** | 不講 | 面額率、級距、與 Max 價格的聯動 |
| **升級觸發點** | 「記憶斷層」這句話怎麼說 | 升級牆的設計與轉化率假設 |

**同一件事的兩面各歸各位，正文互相引用。**
