# 香港商業中文用語表（對外文稿）

> 產出：Workstream D（語言／風險表述）· 2026-10-16（Asia/Shanghai）  
> 適用範圍：**書面計劃書、口頭報告講稿、投影片對外可見文字、答問預案**。  
> Specs／AGENTS 內部可用英文或技術詞（如 Agent、CAC）作對照；**寫進對外文稿時改用本表港式說法**。  
> 本檔只鎖用詞；**不重寫整份計劃書**。

---

## 0. 使用原則

1. **港式標準中文 + 地道商業寫法**：寧願多寫半句白話，也不堆內地科技／路演口號。
2. **產品鎖定**：對外講 **App + 四項核心**（課程生成、多模態上課、課程共享、**就這一節的隨堂提問／隨時問正在學的內容**）。第四核**能力**＝隨時＋課中；**對外標題**用上列措辭，**勿以「AI 基本問答」作計劃書／對外 headline**。應用內的「Agent」只是**組件**，不升格為第五項核心，也不當品類標籤反覆喊。
3. **句式禁令**（與 AGENTS／定位筆記一致）：禁用「不是……而是……」「並非……而是……」；禁用「待定／TBD／TODO」。寫不下就寫「規格未載／本輪不寫進計劃書」。
4. **內部 vs 對外**：下表「禁用／慎用」指**對外文稿**；Specs 可註「內部稱 X，對外寫 Y」。

## 0b. 計劃書語氣與命名鎖（2026-10-17 · Alfred／Notion 後）

| 鎖 | 定案 |
|---|---|
| **人稱** | 全文用 **「我們」**（對外計劃書／講稿） |
| **禁用詞（對外）** | 避免 **「口徑」**——改寫為「說法／表述／定義／怎麼講」 |
| **語氣參照** | Shopify 早期普羅維登範例：白話、具體、少黑話 |
| **第四核對外標題** | **就這一節的隨堂提問／隨時問正在學的內容**（能力＝隨時＋課中；內部可別名「基本 AI 問答」，不作 headline） |
| **產品開發** | 對外／計劃書：**兩人自研、不外包**（勿寫「AI 輔助自研」作公開標籤）；開發款用於接口／工具／預留，不發創辦人月薪、不排外包人月。內部可註一次可用 AI 工具。 |
| **招聘規模** | 勿寫「100 人」。現狀兩人；融資成功且上線後同步招聘；**首年約十餘人量級**，其後隨驗證分階段調整 |
| **學校渠道** | 表下補充／腳註；**不計入本輪個人訂閱收入與增長模型** |
| **Stripe（給非技術讀者）** | 國際常用的線上收款服務；接入後學生可用信用卡等常見方式付訂閱 |

## 1. 核心替換表（禁用／慎用 → 對外優先）

| 禁用／慎用（多見於內地科技／路演腔） | 對外優先（港式商業／白話） | 備註 |
|---|---|---|
| **獲客測試** | **投放廣告，觀望市場反應** | 申請用途名、投影片標題、計劃書段落皆用此向。可補：小額真實廣告費，用來看哪個渠道有反應。 |
| **獲客成本**／CAC（裸寫） | **吸納客戶的成本**；結構段亦可寫 **宣傳成本** | 首次出現可括註「即每成功吸納一名付費用戶所花的宣傳與廣告費」。Specs 內部可留 CAC。 |
| **獲客**（作動詞／標題） | **吸納客戶**／**宣傳與推廣**／**投放廣告** | 避免單獨當章節標題「獲客」。economics 目錄名可暫留；對外目錄改「宣傳與客戶吸納」。 |
| **智能體** | **系統／程式內的問答或生成組件**；或 **自動化助手** | 對外計劃書優先。一句話產品定義用「定制化課程學習平台／學習應用」，勿連喊「AI 智能體」。 |
| **AI Agent**（當品類口號反覆用） | **學習應用／課程學習平台**；組件層寫 **應用內的生成與問答組件** | Specs 內部可寫 Agent；對外第一次可用「自動化助手（應用內組件）」，其後用「組件／系統」。 |
| **痛點** | **實際困難**／**卡住的地方**／**學生每天碰到的問題**／**不足之處** | 英語 pain point 直譯；評審聽來像簡報模板。 |
| **財務錨點**／**無錨點**／**實測錨點** | **推算依據**／**尚無帳單核實的數字**／**待首批真實數據校準的假設** | 「錨點」屬財工／創投黑話。風險段勿用「財務錨點」作小標題。 |
| **沒有實測值，需等上線後再調整**（及同類被動句） | 見 `go-to-market-and-risk-framing.md`：**已備措施 + 可驗證指標 + 時點** | 被動「再調」像未準備；改寫成「我們會用 X 量度 Y，於第 N 個月對照推算」。 |
| **真錢投放**（作口號） | **真實廣告費投放**／**小額付費廣告測試** | 「真錢」略口語煽情；對外寫清楚是廣告費。 |
| **測出真實 CAC**（裸寫） | **量度吸納一名付費用戶實際花多少宣傳費** | 與「投放廣告，觀望市場反應」配套。 |
| **藍海** | **這個品類仍早／尚未有人跑出穩定形態** | 已有規格可用後者；避免空喊藍海。 |
| **閉環**／**最小閉環** | **完整學習流程**／**從生成到驗收走完一輪** | 工程黑話；對外講學生實際做什麼。 |
| **賦能**／**抓手**／**打法**／**心智** | 直接寫做法：例如「用口碑與學校渠道為主，付費廣告只作小額觀望」 | 路演腔；委員會場景不需要。 |
| **引爆**／**裂變**／**增長黑客** | **轉介紹**／**口碑**／**可控的宣傳試驗** | 同上。 |
| **用戶畫像**（當標題堆砌） | **我們先服務誰**／**首批對象** | 可保留「畫像」於產品 Spec 內部。 |
| **落地**（動詞濫用） | **做到**／**推出**／**在課堂裡用起來** | 「把方案落地」→「把方案做出來並讓學生用上」。 |
| **對標** | **對照**／**與××比較時** | |
| **賽道** | **品類**／**這個市場** | |
| **顆粒度** | **細到哪一層**／**詳細程度** | |
| **心智佔有**／**心智佔領** | **讓人記得我們解決哪一件事** | |
| **MVP**（裸寫過多） | 首次：**可試用的第一版產品**；其後可寫「第一版」 | 里程碑內部可留 M1／MVP。 |
| **付費牆**／**升級牆**（對外） | **升級提示**／**額度用盡時的選項** | Specs 內部可留。 |
| **口徑**（對外正文） | **說法**／**表述**／**定義**／**怎麼講** | Specs 內部技術「口徑」可暫留；計劃書避免。 |
| **AI 基本問答**（作對外標題） | **就這一節的隨堂提問／隨時問正在學的內容** | 能力仍＝隨時＋課中；標題層用右欄。 |
| **100 人**（招聘承諾） | **首年約十餘人量級**（上線後再招） | 不以固定大數作承諾。 |

## 2. 產品相關：內部詞 ↔ 對外詞

| Specs／對內常用 | 對外計劃書／講稿 |
|---|---|
| AI Agent／成課 Agent／授課 Agent | 應用內的**生成組件**／**講解組件**／**問答組件**；或統稱「系統裡協助備課與答問的自動化助手」 |
| Agent 貫穿每一環 | **四項核心功能串起完整學習流程**（生成 → 上課 → 共享 → 就這一節的隨堂提問／隨時問正在學的內容；檢測／追溯等為支撐機制） |
| 獲客測試（HK$80,000） | **投放廣告，觀望市場反應**（預算 HK$80,000） |
| CAC | **吸納客戶的成本**（或宣傳成本） |
| LTV／churn／CAC payback | **對外不寫**（同業未披露；見 pitch-part3／financial-model 禁用） |
| 財務錨點／無實測錨點 | **推算假設尚未經帳單核實**；全文標「這是推算」 |
| 痛點（競品／檢驗） | **現有產品的不足**／**學生驗收時碰到的困難** |

## 3. 易混詞：保留 vs 改寫

| 可保留（有定義或已是港式） | 說明 |
|---|---|
| **推算** | 財務圖表頁腳必用；優於「我們還沒有數據」。 |
| **宣傳成本** | 結構／用途表可用；與「吸納客戶的成本」同義時選一處統一。 |
| **投放**／**廣告投放** | 可用；搭配「觀望市場反應」，勿只寫「獲客」。 |
| **內測**／**試用** | 可用。 |
| **里程碑**／**驗收指標** | 可用；每項用途掛可核對結果。 |
| **理論錨點**（引用文獻時） | 僅限學術出處語境；**勿**借去寫財務。 |
