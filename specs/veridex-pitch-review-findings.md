## 🔴 致命（不改不能上台）

### 1. 对比度全面不及 AA —— 22/22 页，101 处
实测（WCAG AA 需要 4.5:1，大字 3:1）：

| 前景 / 背景 | 实测 | 命中 |
|---|---|---|
| `#C07A16` on `AMBER_SOFT` | 2.96:1 | P5 P8 P13 P15 P22 |
| `#2F6BFF` on `#F6F7F9` | 4.20:1 | **全部 22 页的 kicker** |
| `#6B7684` on `#F6F7F9` | 4.31:1 | 全部页码 + 全部脚注 |
| `#C07A16` on `#FFF` | 3.48:1 | P4 P6 P12 |
| `#C07A16` on `#F6F7F9` | 3.25:1 | P5 P8 P15 P16 P17 |
| `#2F6BFF` on `BLUE_SOFT` | 3.80:1 | P8 P11 P12 P13 P16 P18 P19 P20 |

**修法**：把「用作文字的颜色」与「用作填充/边框的颜色」分开。
```ts
const ACCENT     = 'var(--osd-accent)';  // #2F6BFF — 填充、条形、边框（图形需 3:1，达标）
const ACCENT_TXT = '#1B4FD8';             // 文字用，对 #F6F7F9 ≈ 5.6:1
const AMBER      = '#C07A16';            // 填充、边框
const AMBER_TXT  = '#8F5606';             // 文字用，对白 ≈ 5.9:1，对 AMBER_SOFT ≈ 4.9:1
const DIM        = '#5F6B79';             // 从 #6B7684 调深，对 #F6F7F9 ≈ 4.62:1
const MUTED      = '#5A6675';            // 已达标
```
**执行方式**：把所有 `color: ACCENT` 改成 `color: ACCENT_TXT`，所有 `color: AMBER` 改成 `color: AMBER_TXT`。**注意不要动** `background`、`border`、`fill`、`stroke` 里用 ACCENT/AMBER 的地方。审完用同一套方法复测。

### 2. P4 落点句把未经验证的前提当公理，且与自己三页后矛盾
现状：「不是學生不夠努力，是這件事人做不來——所以必須由系統來做。」
问题：只证明了**学生自己**无法自评，没排除「由人验收」；而 P15 / 附录 B 都说分数由**授课教师**判。
**改法**：落点改为「**判斷的人必須站在學生之外**」，然后用三条可辩护理由说明为什么在**学生端**必须是系统：**一致性、可规模、24 小时**。这与 P15 的教师复核机制自洽。

### 3. P13 前置知识链数学上不成立
现状：中央極限定理 → 樣本平均與期望 → 分佈的加法 → **分式運算**
问题：中央極限定理的前置是独立同分布变数的期望／变异与正规化，不是中中学分式运算。**CLC 是量化素养课程**，导师或评委极可能一眼看穿。
**改法**：换成一条真实成立的链。**推荐用概率链**（更安全，不涉及 CLC 正在教的微积分）：
```
條件機率 → 期望值與變異 → 樣本平均 → 中央極限定理
```
如果用户要保留「盲點很驚訝」的反差，**【待用户确认】**：他们需要一个真实但有反差的例子。

### 4. 全篇没有资金需求
受文者是「青年創業基金委員會」，grep `資金/融資/申請/預算/投資額/募資` **0 命中**。听完 20 分钟不知道要批什么。
**改法**：在 P20 收束句上方加一行明确的 ask。
**【待用户填】** 金额、用途、换什么。占位格式：`首年要 HK$【X】，用在 ①原型 ②校园部署 ③模型成本；解锁条件＝第 6 月 100 人真实使用。`

### 5. P15「三個月內」与 P20 时间线矛盾
P15 lead：「三個月內，我們請試點學校用這三個數字判斷我們」——但三个数字含「30 天後回訪」。
P20：第 3 月才交原型，第 6 月才封闭测试。**带日历的评委一问即穿。**
**改法**：P15 改为「三個月內簽約並備課，第 6 月封閉測試後交出第一份數字」；P20 第 3 月改为「可用原型 ＋ 試點學校簽約」。

### 6. P16「數據不出境」与 P17「首年主攻香港與內地大學生」冲突
「境」在页面上未定义；若指香港，内地大学生怎么办；用境外 LLM API 必然出境。
**改法**：
- P16 改为「數據留在用戶所屬司法區（香港用戶留港、內地用戶留內地）」
- 附录 B 补一句「模型我們自託管／或在當地部署，不經境外 API」

### 7. P16 两处「已交付物：［待填］」未填
**【待用户填】**。若真的没有，删掉该行，改讲真实存在的东西（如「已交付物：3 个入口的可用原型 ＋ 1 门试讲课」）。

## 🟠 重要

### 8. 两处违反 spec §2.6 措辞禁令
- P8：`「第三步也擠滿了——只是全都停在「判對錯」。」`
- 附录 B：`「它們把驗收做到判對錯。…」`
spec 明文规定只能用「公開資料裡看不到任何一家說明……」。P7 的讲者备注甚至写了「不要說它們沒做」，附录那句正是禁止的写法。
**改法**：P8 →「第三步也擠滿了——只是**在我們查得到的公開說明裡**，都停在判對錯。」附录 B →「它們的**公開說明裡**，驗收做到判對錯。」

### 9. P8「掌握度衰減，沒有人在追」会被 Quizlet 推翻，且 P14 又认领同一件事
间隔重复是 Anki/Quizlet 用了二十年的成熟品类。
**改法**：把概念切开——「排複習」是 SRS 在做的（人人都在做）；「**用同一套驗收反覆量你還剩多少**」是公开资料里看不到的。P14 的「間隔重複」也要改成不与他人冲突的表述。

### 10. P5 落点句强度超过证据
HEPI 是选项清单，清单没列 ≠ 该行为不存在（2026 年学生极常向 AI 要练习题）。
**改法**：落点降级为「這份問卷裡，AI 是拿來解釋的；**沒有人問過它拿來考自己**。」

### 11. P2 开篇与 P20 收尾不是同一个问题
P2 问「必須經過什麼」（过程），P20 答「不是他自己說了算」（权限）。
**改法**：P8 的三个方框 kicker 改成「一個人學會一件事，必須經過三步」，或 P3/P4 加一句把 P2 答掉。

### 12. P19「ChatGPT Plus US$20」在 spec 和附录 A 都没有出处
**改法**：删掉该行（结论句不依赖它），或补进附录 A。**默认删掉。**

### 13. P14 Sweller 引用越界
「心理學的認知負荷理論說：別讓它去管雜事」——Sweller 讲的是解题工作记忆负荷，不是「把杂务交给系统」。
**改法**：「我們借用認知負荷理論的思路：腦的容量有限，別讓它去管雜事。」

### 14. P6 漏掉「買題庫自測」，而 P7 自己说 Quizlet 最完整
**改法**：P6 补第四栏「買／找現成題庫」→ 代價寫「題目跟你的課不對焦，錯了也不知道錯在哪一步」。

### 15. P6「現在主要是三種土辦法」无一手根据
P20 显示 30–50 次深访是**第 3 月**才做的里程碑。等于零用户研究撑起一整页「现实描述」。
**改法**：lead 改为「我們看過的做法」。

### 16. P15 三个数字零依据
**改法**：每个数字加一行小字「與試點教師共同議定」；「任務」改成「教師指派的學習任務」。

### 17. P7 把「我們查不到」写进了「產品的局限」栏
Hyperknow 局限栏写「檔位命名查無公開記錄」——这是研究者没查到，不是产品做不到。
**改法**：移出该栏，或改为「檔位命名未公開，無法對照其能力邊界」。

### 18. P7 把开源研究框架当同级竞品，且 #1712 已有修复 PR
OpenMAIC 是清华开源框架（39,617 stars），不是付费商业产品；#1712 在 2026-09-29 同日已有修复 PR #1713（未合并）。
**改法**：标注为「開源課堂框架（清華 MAIC 團隊）」，并写明「社群 issue #1712 回報選項重複導致判分錯誤，修復 PR 已提交未合併」。

### 19. P18 把内部备忘印在对外定价页
「積分的絕對數值待成本測算後補上；本頁只寫比例。」——给基金委员会看等于当场承认没做单位经济。
**改法**：改成正面陈述「所有檔位的積分足以跑完 N 次完整驗收；我們只收成本，不賺價差」，备忘移进 notes。

### 20. P19「模型路由」未解释
非技术受文者不认识这个机制。
**改法**：「簡單題用小模型、難題用大模型，所以額度可以預先算準」。

### 21. 时间预算不成立
逐页念完约 20.3 分钟，而规定是 20 分钟**连问答**。问答时间为零，而互动交流占评分 20%。
**改法**：在 notes 里明确三处压缩点——**P14 整页删**（视觉审核判定它是最弱页且是装饰）、P7 只念前三列、P19 只念两行价格。

### 22. 对比度之外的具体版面缺陷
- **P3 两卡高度差 135px**（右卡写死 `height: 470`）→ 删掉该写死值，靠 grid 拉满
- **P15 / P16 同一句交接语重复**，且 P16 标题就是「憑什麼信你」而页脚说「下面才要说我们是谁」→ 删 P16 的 handoff
- **P8 琥珀面板右半 1000px 全空**（三行只占左半）→ 改成 `grid repeat(3,1fr)` 横排或收窄面板
- **6 页有 180–420px 空白带**（P2 420px 最严重）→ 收掉卡片的等高绑定，把空间给底部结论条
- **交接标记用琥珀** → 违反「橙色只代表问题」的视觉叙事，改 MUTED
- **P18 定價三栏是装饰**（P6/P12/P18 四页同构，超了「单一版式≤3 页」）→ 至少改掉一页的骨架

### 23. 错字与小瑕疵
- P16 `「分戶隔隔離」` → 「各校資料分隔」（户 在中文读作家户）
- P9 两条泳道都用 ①②③，听众分不清 → 人的用「人①②③」，AI 的用「AI①②③」
- P20 右上角只写「黃浩然」但两人同台 → 改「黃浩然 · 黃羿捷」
- P19 `tag=""` 是死码 → 补文字或删属性
- P3 notes 混入简体「接下一页」→ 改繁体
- 附录 A 有 2 条只有刊名年份无作者篇名（正是 P4 跨学科佐证的唯一支撑）→ 补全或删
