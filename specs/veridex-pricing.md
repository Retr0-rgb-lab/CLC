# Veridex 維學 — 定價規格

> 依據：本輪兩份調研（模型 API 成本／競品套餐與權益分層）+ 內部定價決策
> 狀態：待使用者確認數值
> 配套文件：`veridex-product-philosophy.md`

---

## 0. 設計原則（決定了下面所有數字）

1. **積分不綁「每節課」，要綁「實際用掉的分鐘數與 token」。** 理由：一節課在不同技術路線下真實成本可差 4–8 倍，用固定積分扣費會讓高成本路徑吃掉 4–8 倍毛利。
2. **只在創造新東西時扣積分，看已生成的內容免費。**（抄自 Hyperknow 已上線的規則）
3. **失敗全退。** 生成失敗或使用者取消，全額退回。
4. **不跨週期累積。** 用不完的月底清零。

> 原則 2–4 與 Hyperknow 官方 credits 說明中的規則一致（從其應用 bundle 抽出的原文），**可直接引用「已有上線產品是這麼做的」**。

## 1. 三檔套餐

| | **免費** | **Pro** | **Max** |
|---|---|---|---|
| **價格** | HK$0 | **HK$78 / 月** | **HK$150 / 月** |
| **每月積分** | 100 | 800 | 1,600 |
| **約合** | 10 節課 | 80 節課 | 160 節課 |
| 相對免費版 | 1x | **8x** | **16x** |
| 積分每課換算 | 10 | 10 | 10 |

### ⚠️ 一個必須知道的結構問題

**HK$78 → HK$150 只有 1.92 倍，而業界最高檔的慣例是 5–20 倍**（Claude Max 5x／20x，ChatGPT Pro 讓你選 100／200／500）。

**所以 Max 的差異化必須寫在「能力」上，不能只寫在「量」上。** 量只是跟著價格等比放大（800:1600 ≈ 78:150），它撐不起一個獨立檔位。

調研同時發現一個 2026 年的趨勢，可引用：
> **ChatGPT 與 Claude 的最高檔，都已從「能力包」退化成「用量轉盤」**——新增的實質能力極少。

**我們的對策**：Max 額外給三樣「量以外」的東西——更強的模型檔次、20GB 空間、連接器不限。

## 2. 權益對照

| 權益 | 免費 | Pro | Max | 借鑑的業界先例 |
|---|---|---|---|---|
| **積分額度** | 100 | 800 | 1,600 | 最普遍，無需解釋 |
| **模型檔次** | 固定中檔 | 可開啟路由 | **疑難優先用強模型** | 業界第一順位（Claude／ChatGPT／Google 都把模型檔次當頭號賣點） |
| **雲端空間** | 200 MB | **5 GB** | **20 GB** | Google：400GB→2TB→5TB→20TB→30TB 的純階梯 |
| **連接器（MCP）** | 1 個 | **5 個** | **不限** | Notion：Basic→Premium→Advanced 三級階梯 |
| **延遲回訪** | ✗ | ✓ | ✓ | 我們的差異化功能 |
| **高峰優先** | ✗ | ✗ | ✓ | Claude Max 唯一明文的付費賣點 |

### 權益的措辭紀律（重要）

| 項目 | 必須怎麼講 | 為什麼 |
|---|---|---|
| **連接器** | 只能說「**能連幾個、連到什麼級別**」 | Claude 的 Connectors **四檔全免費**、ChatGPT 的消費級 apps 也全免費。**不能說「業界都收連接器費」**——那是假的。可引的先例是 Notion 的三級階梯（Free 完全無連接器） |
| **雲端空間** | 可以硬收費 | 存儲是業界最乾淨的付費點（Google 教科書級） |
| **記憶** | 不要作為付費權益 | Claude Memory 四檔全免費；ChatGPT Memory 只從「Limited」升到「Expanded」，**從未硬鎖**。硬鎖記憶會很難看 |
| **資料同步** | ⚠️ **依據最弱，建議不單獨列** | 調研明確：NotebookLM 的 Drive 自動同步**免費檔就有**；Notion 的資料庫同步限 Business 以上，但屬企業流程整合。若要保留，必須定位成「**學校／機構的批量同步**」——那才有付費依據 |
| **模型路由** | 講「同一份額度更耐用」，**不講「我們用便宜模型」** | 說便宜模型會被理解成次品。講「每個成功任務的總成本」才是重點（廠商官方文件原話） |

## 3. 積分消耗規則

| 行為 | 消耗 | 說明 |
|---|---|---|
| **上一節課**（10–15 分鐘語音 + 檢測） | **10** | 這是使用者唯一需要記住的數字 |
| **生成一門專業課** | **100** | ≈ 10 節課，按節數換算，使用者不需學新算術 |
| **微調一次** | **3** | 見下方 ⚠️ |

⚠️ **微調收費是一個沒有同類先例的決定。** 調研發現：Hyperknow 的六項收費裡**沒有「微調已生成的課」**——它的練習、測驗、項目都是「首次開啟才計費」，重新打開免費。

- **好處**：保護「自由度」這個核心賣點。**如果改要額外付錢，使用者就會克制地改，那個「可改」就只剩形式。**
- **風險**：使用者可能覺得「隨便改兩下就要花錢」

**講法必須是「改動有邊界」而不是「省成本」**：
> 可以反覆改，但重做整門課不另外計費。

## 4. 加油包

| | 數值 |
|---|---|
| **價格** | **HK$6 = 50 credits**（約 5 節課） |
| 折算單價 | **12 港元 / 100 credits** |
| 對比 Pro | 9.75 港元 / 100 credits |
| **溢價** | **比訂閱貴約 23%** |
| 誰能買 | **只有 Pro 和 Max；免費檔不能買** |
| 有效期 | **30 天過期** |

### 為什麼故意賣得比訂閱貴

**這是業界慣例，而且有可引用的機制依據：**

- Google 官方明文 credits **會過期**，且 **AI Plus 檔明文排除**、只有 Pro／Ultra 能買
- ChatGPT **只有 Business 與 Enterprise 能買**，個人檔（含 Pro）不可

**若加油包更便宜，使用者會囤積而不是長期訂閱——那會直接毀掉續訂率。**

### ⚠️ 查不到的東西

**所有產品的加油包美元單價都藏在登入後的帳戶頁，官方說明頁不寫。** 因此**「加油包是原價幾折」這個問題，全業界沒有可引用的官方答案。**

我們的 HK$6／50 credits 是**內部定價決定，不是引用業界慣例的結果**——寫 deck 時必須這樣表述，不能說「業界都是這樣」。

## 5. 可以引用 / 不可引用的清單

### ✅ 可引用（有官方出處）

| 內容 | 出處 |
|---|---|
| 「只在創造新東西時扣，看已生成的免費」 | Hyperknow 官方 credits 說明（應用 bundle 原文） |

| 連接器按「數量與廣度」分級 | Notion 三級階梯（Free 完全無連接器） |
| 加油包只給中／高檔，credits 會過期 | Google 官方（明文排除 Plus）；ChatGPT（僅 Business/Enterprise） |
| 「高峰優先」可以做成付費賣點 | Claude Max（本次唯一明文這樣寫的產品） |
| 最高檔已從能力包退化成用量轉盤 | ChatGPT Pro 100/200/500；Claude Max 5x/20x |
| 判據是「每個成功任務的總成本」 | 廠商語音成本指南原話 |

### ❌ 不可引用

| 內容 | 原因 |
|---|---|
| **所有模型的 API 單價** | 官網被 Cloudflare 阻擋，數據來自第三方代理，模型名無法獨立核實。**僅作內部測算輸入** |
| **Hyperknow 的 credits 數字** | 官網不公開，真實數值需登入後由 API 注入 |
| **Hyperknow 的 $0/$18/$50 價格** | 兩次調研結果矛盾（一次說三檔，一次說只有 $50 露出）。**二手轉述，不能用** |
| **「Hyperknow 免費一天 4 條訊息」** | 僅出現在一位用戶自述中，且描述的是舊制 |
| **任何「1 節課 = N credits」的業界慣例** | 沒有任何產品公布過這類數字 |
| **任何加油包的折扣率** | 全業界無公開數字 |
| **Khanmigo／Duolingo 的價格** | 官方頁面查不到（Duolingo 是 SPA，Khanmigo 已併入 khanacademy.org） |
| **ChatGPT Go 檔、Google 四檔的價格** | 頁面為 JS 動態載入，raw HTML 無數字 |
