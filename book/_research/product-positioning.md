## 0. 書面計劃書 QA 約束（Standing，全程遵守）

1. **語氣／人格**：初次創業的大學畢業生，對「青年創業基金委員會」說話。自然、可核對、不堆口號；避免 AI 腔與標語疊加。
2. **句式禁令**：禁用「不是…而是…」「並非…而是…」對偶否定。一律改寫成肯定句（「我們是…／我們做…／我們包含…」）。  
   - 依據：`市场规模-运营流程-行业位置.md` §一語言紀律（2026-10-05 用戶裁定）；本輪 parent steering 再確認。
3. **禁用「待定／TBD」**：寫不下就寫「規格未載／本輪不寫進計劃書」，不許留空位詞。
4. **其他禁令（來自產品規格）**：不把「不限於單一垂直場景」單獨當市場定位；不寫「全自動幫你學」；不寫無依據的「我們比 XX 強」；不自造「第 N 格／最小閉環」等詞；技術細節若上計劃書須有白話括註。

## 1. 一句話產品定義（定稿候選）

### 鎖定句（肯定句，可進計劃書）

> **Veridex 維學是為學習而生的課程學習應用程式：按你的需求生成專屬課程，提供多模態課堂體驗，支援使用者之間共享課程，並附帶基本 AI 問答；以每節 10–15 分鐘課為單位講解與驗收，並跨堂記住你上次卡在哪。**

### 產品身份與四大核心（定案）

| 項 | 定案 |
|---|---|
| **產品身份** | **應用程式**（課程學習應用）。AI Agent／智能體只是應用內組件（尤其服務生成流程與基本問答），**不是產品本身** |
| **核心功能（恰好四項）** | ① 課程的生成 ② 課堂上課（多模態課堂體驗） ③ 課程的共享 ④ 基本的 AI 問答 |
| **非核心** | 檢測、追溯、間隔重複、知識庫、畫像記憶等 → 支撐／機制，不升格為第五項核心 |

### 拆開的三層（寫長段時用，不要壓扁）

| 層 | 內容 | 出處 |
|---|---|---|
| 產品是什麼 | **課程學習應用程式**（四大核心見上） | `philosophy` §1／§1b |
| 依據 | **你的需求**（資料是需求的一種；也可以是一句話） | `market-ops` §4.1 |
| 產出 | **專屬於你的課程**（章節→知識點→每節帶檢測） | `philosophy` §4.2；`market-ops` §4.1 |

應用內的 Agent／生成組件讀懂需求、協助決定教什麼與怎麼教——寫計劃書時可作**組件說明**，勿寫成「Veridex＝Agent」。

### 封面／副標可並用（已定案，勿改宗旨式標題）

- 主標：`Veridex：AI 時代的有效自學方案`
- 副標：`按你的資料生成，按你的程度驗收`  
  （`veridex-pitch-product-spec.md` P1）

### 須改寫的舊句（規格原文含對偶否定或舊身份，計劃書禁用對偶否定句式）

| 規格原文（舊） | 計劃書改寫 |
|---|---|
| 「Veridex 是一個為學習而生的 AI Agent，不是 AI 做的課。」 | 用上方鎖定句（應用程式＋四大核心）；必要時補一句價值：「我們賣的是讓通用模型在『學習』這件事上穩定工作的那套應用與機制。」 |

## 2. 問題診斷（非 CS 用語）

面向委員會：講「學生每天碰到的事」，不講架構／token／agent 內部。

### 問題一：課對所有人是同一份

- 老師的注意力稀缺：一份講義、一條進度，只能按「一個人」來排。  
- 結果：快的被拖、慢的掉隊；你真正想學的起點，課堂往往對不上。  
- 出處：`pitch-product-spec` P2；`market-ops` §4.1c 左欄。

### 問題二：學完之後，很難知道自己到底會不會

- 學會一件事要走完「喚起先備 → 示範 → 應用 → 整合」；後兩步必須自己動手，動手之前沒有人知道你會了多少（Merrill 2002，計劃書可腳註）。  
- 學生自己做檢驗的少；自己判斷程度時又容易估不準（元認知錯覺：對自己掌握程度的判斷與真實水平不一致）。  
- 一題做錯了，真正要答的是四件事：掛在哪個知識點、為什麼錯、補哪一塊、多久再問一次——多數產品只碰到第一層。  
- 出處：`pitch-product-spec` P5–P8；`OUTLINE` 問題二。

### 計劃書可用的兩段診斷（自然口語示意）

1. 「傳統課堂裡，課是發給全班的。進度也是全班同一條。你跟不上或超前，都只能硬跟。」  
2. 「就算自己找 AI 幫忙，也常常不知道自己到底過關沒有：少做檢驗，做了又容易估錯。錯了一題，也很少有人帶你追到真正不會的那一層。」

## 4. 核心循環／用戶旅程步驟

### 循環單位（產品最有價值的設計參數）

- **一節課 = 10–15 分鐘實時語音教學**（可打斷、追問、要求換講法；白板板書同步）。  
- 一門課沒有單一「全部完成」的終點；**一節課有完成態**——學完檢測，就能知道這節有沒有白聽。  
  （`philosophy` §4.1；`README` 速查）

### 用戶旅程（寫計劃書用的步驟序）

1. **提需求**：上傳講義／題目，或直接說「我想學 X／我卡在 Y」。  
2. **應用澄清需求**：追問補齊缺口、摸清程度（可由 Agent 組件執行；**不要拆成與「定制」並列的兩個賣點**）。  
3. **生成課程**：章節 → 知識點 → 每節 10–15 分鐘，課自帶檢測。  
4. **上課**：語音講解 + 板書；進度跟你的反應走。  
5. **追問／換講法**：當場打斷，直到弄懂（消耗積分；唯一免費動作是回看已生成的課）。  
6. **檢測**：選擇題／主觀題／項目；過關才往下。  
7. **追溯**：錯了不整段重做——追到真正不會的那一層，只補那一塊；追多深由你決定。  
8. **間隔重複**：間隔由「要保留多久 + 用哪種測試」算出，你確認；可連日曆提醒。  
9. **回看**：復看已生成課（免費）。

### 激活定義（若計劃書寫運營／里程碑時用）

> 激活 = **24 小時內完成一整節 10–15 分鐘課 + 通過 1 個知識點驗收**。  
> （不可寫成「發出第一條訊息」；若引用須同頁帶 Khanmigo 96%／17% 參與證據，否則委員會會當自定口徑。）

### 產品身份＋四大核心（講「我們做什麼」時用）

| 層 | 白話 | 少了會怎樣 |
|---|---|---|
| **應用程式** | Veridex 本身：把生成、上課、共享、問答收成一套學習產品 | 只剩散落工具，沒有產品形態 |
| **四大核心** | 課程生成／多模態上課／課程共享／基本 AI 問答 | 任一缺失，產品主張不完整 |
| **Agent 組件（非身份）** | 讀懂需求、協助生成與問答 | 生成與問答變弱；**仍須寫成組件，勿升格為產品名** |
| 支撐機制 | 檢測、追溯、間隔重複、知識庫等 | 體驗變薄；**不列入核心功能四項** |

## 5. 模型策略（計劃書可寫、須帶白話）

### 定案（與任務要求一致，規格已寫）

| 場景 | 策略 | 白話括註 |
|---|---|---|
| **課程生成** | **一律用前沿／頂層大模型** | 出整門課、章節與知識點時，用當下最強可用的那一檔，保證課的骨架質量 |
| **課中實時問答／追問** | **按難度做模型路由** | 簡單問題走較省的模型；疑難走較強模型——你付的月費／積分感知不變，我們控制成本 |
| 全檔共通 | Free／Pro：生成＝前沿；問答可路由。Max：**生成一律頂層；即時問答路由（疑難走強）** | `pricing`／`part2` 權益表 |

### 架構一句（內部清楚、對外可極短）

- 產品語音主路徑是 **大語言模型先寫出要講的內容，再轉成語音播出**（LLM + TTS），重點是「能打斷的教學節奏」，計劃書不必展開供應商單價。  
- 積分與底層模型成本**解耦**：同樣積分消耗量可路由到不同價位模型——這是毛利控制，也是與 Hyperknow「積分＝成本鏡像」的架構差別。  
- **禁止**對外報未核實的模型 API 單價；可講「用的是公開可得的模型，必要時可報型號」。

## 6. 競爭定位：有據 vs 脆弱

### 有據（可寫進計劃書／答問，須標出處等級）

| 主張 | 依據邊界 |
|---|---|
| 最像我們的產品形態是 **Hyperknow**（從零生成、有測驗、賣積分） | 須誠實面對；App 內訂閱彈窗＋媒體種子輪報導 |
| Hyperknow：**沒有手機 App**；私隱政策寫用戶 **should not upload** 受專業特權保護的資料 | 官網／私隱政策 [A]（取證日見 part2／part3） |
| Coursera 有語音對話，但**不支援中文**、語音路徑對 App 有限制——對香港學生很傷 | 官方說明 [A]；禁止說「它們沒有語音」 |
| DeepLearning.AI：**無語音即時教學**這條線 | 會員頁可核 |
| LearnVector（Coursera 投資約 US$1 億）：**仍在開發中** | investor.coursera.com [A] |
| 我們的積分是**穩定價目**（背後模型由我們調）；Hyperknow 積分更接近**成本鏡像**（提問／傳檔直接扣分、窗口重置） | 架構差異可講；**禁止把兩邊積分數字並排換算倍數** |
| 錯題四問（掛點／原因／補哪／何時再測）vs 多數產品主要停在第一層 | 產品設計主張；對競品只能說「公開資料裡看不到完整四步」，不可說「沒有人做檢驗」 |
| 品類仍早：最像的一家是種子輪量級；有資源的玩家產品未上線完整形態 | 可作「為什麼是現在」；須立刻接回「Agent + 課程功能」兩構成，避免空喊藍海 |
| 內容做薄：課從用戶資料生成，成本隨使用長，不靠自建海量題庫 | Chegg 收入下跌可作「內容庫不構成護城河」的旁證 [B] |

### 脆弱／禁用（計劃書與答問都不要主動踩）

| 說法 | 為何脆弱 |
|---|---|
| 「檢驗這格沒人做／他們沒做反饋」 | **事實錯誤**（StudyFetch／Mindgrasp／Quizlet 都有） |
| 「我們的模型更強」 | 底層是同行公開模型 |
| 「課程庫是我們的護城河」 | 內容可生成與搬運；頁面**不講護城河** |
| 無依據的「我們比 XX 強」 | 當場可被推翻 |
| 積分數字並排、量折扣對比 Hyperknow | 單位定義不同，算完會翻車 |
| 「全自動幫你學」 | 與「學習之內不插手／要動手檢驗」衝突 |
| 把「不限垂直場景」單獨當市場定位 | 聽起來像還沒想清楚服務誰 |
| 補習市場金額（HK$4 億–281 億等） | 無統一方法論，禁用 |
| 產品「已上線／已有用戶」口吻 | 現狀：原型未完成、零用戶——計劃書須誠實為設計／申請啟動 |

### 答問備用（不上正文亦可）

- 護城河口頭答：真實使用留下的「哪層不會、哪種講法有效」才長得成壁壘；現在零用戶，這筆錢買的是開始累積的第一批用戶。  
- 幻覺：結構上「每個知識點可追到來源」；**自有幻覺率無數據**。  
- 作弊：追溯閘門「不懂才解鎖下一層」方向有 Bastani 等護欄文獻；**本校／DSE 條款與自有數據未核**。
